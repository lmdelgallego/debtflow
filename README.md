# debtflow
DebtFlow es un micro-SaaS para personas con ingresos fijos o variables que quieren salir de deudas usando un método claro y automático (avalancha). Permite registrar ingresos, gastos y deudas, calcular el flujo mensual real y definir exactamente qué deuda atacar primero, sin hojas de Excel complejas ni asesorías costosas.
